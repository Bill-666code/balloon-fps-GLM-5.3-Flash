# 气球人大作战 · Balloon Pop FPS

一款气球人主题的浏览器第一人称射击游戏。**枪械、角色、地图、贴图、战斗特效、音效与音乐全部由代码实时生成，零外部素材文件**（three.js 为本地代码库，非素材）。

## 玩法

派对上空飘来一支气球人大军，用你的玩具枪把它们全部打爆！坚守一波又一波进攻，拿高分。

- **WASD** 移动 · **鼠标** 瞄准 · **左键** 射击
- **Space** 跳跃 · **Shift** 疾跑 · **R** 换弹 · **1/2/3** 或滚轮切枪
- **P** 暂停 · **M** 音乐开关

### 三把代码生成的玩具枪

| 武器 | 特点 |
|---|---|
| 🔵 水枪 SOAKER | 连发水珠，弹匣 32 发，射速快后座小 |
| 🟢 飞镖枪 DART | 单发高伤 46，精度极高，扎胖子神器 |
| 🔴 彩纸炮 SCATTER | 一次 8 发彩纸散射，近距离一炮一团 |

### 五种气球人

| 气球人 | 行为 |
|---|---|
| 红色·波波 | 普通冲锋 |
| 蓝色·疾疾 | 高速逼近，近身会猛冲 |
| 绿色·胖胖 | 130 血大块头，慢慢挤过来 |
| 金色·闪闪 | 之字走位，击杀必掉星星（+400 分） |
| 紫色·泡泡 | 远程吐水球，需要走位躲避 |

连击（3 秒窗口）最高 ×4 分数加成；击杀有概率掉爱心 / 弹药；波次间自动回血 15 点。

## 全代码生成清单

- **贴图**：地面粉彩方格 + 彩纸屑、气球皮渐变、气球脸（微笑/受伤 X 眼）、条纹雨棚、木板、树篱、棒棒糖树冠漩涡、云朵、天空渐变 —— 全部 Canvas 2D 绘制
- **角色**：气球人（球体 + 球面贴图脸 + 摆动手脚）、三把枪的视图模型（盒子/圆柱拼装，带换弹/切枪/后座/摇摆动画）
- **地图**： carnival 竞技场 —— 美食摊位、木箱堆、棒棒糖树、气球拱门、系留气球、彩旗、6 座刷怪彩门、棉花糖山丘
- **特效**：气球爆裂（橡胶碎片 + 彩纸 + 冲击环 + 火花）、枪口火光、水花、伤害数字、会心一击、屏幕震动、命中标记
- **音频**：WebAudio 全合成 —— 枪声 ×3、爆裂、换弹、受伤、拾取、号角、凯歌、橡皮吱吱、脚步，以及一段五声音阶生成式背景音乐

## 运行

```bash
cd balloon-fps
python3 -m http.server 8642
# 打开 http://localhost:8642
```

需要键盘 + 鼠标的桌面浏览器（Chrome / Edge / Safari 最新版）。

## 技术

- three.js 0.186（本地 ESM，importmap 引入）
- 原生 JS ES Module，无构建、无框架
- `js/core.js` —— 渲染器 / Canvas 纹理工厂 / 粒子池 / 合成音频
- `js/game.js` —— 地图 / 玩家 / 武器 / 敌人 AI / 波次 / HUD / 主循环
- 调试钩子 `window.__game`（start / spawn / step / aim / shoot / stats …）
